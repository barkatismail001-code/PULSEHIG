## 🌍 Languages

TechPulse supports 5 languages:
- 🇬🇧 English

- 🇪🇸 Español (Spanish)

## 📚 Topics Covered

- **Embedded Systems**: ESP32, ESP8266, STM32, Arduino
- **IoT & Firmware**: MQTT, OTA updates, sensor integration
- **Petroleum Engineering**: Upstream, midstream, downstream
- **Natural Gas**: LNG processing, pipelines, shale gas
- **Programming**: Python, C, Embedded C, Git, APIs

## 🏗️ Architecture

- **Frontend**: Vanilla HTML/CSS/JS (no framework)
- **Backend**: Supabase (PostgreSQL + Realtime + Auth)
- **Hosting**: GitHub Pages
- **SEO**: Static generation via `scripts/generate-seo.mjs`
- **AI Discovery**: `llms.txt`, `.well-known/ai-plugin.json`
- **PWA**: `manifest.json`, `sw.js`

## 🚀 Features

- ✅ Multi-language (5 languages via `js/i18n.js`)
- ✅ Dark mode with system preference detection
- ✅ Service Worker for offline support
- ✅ Live news ticker (Hacker News API)
- ✅ Community forum with Supabase Auth
- ✅ AI-powered article generator (Groq + Qwen Vision)
- ✅ Full SEO with Schema.org (Article, FAQPage, BreadcrumbList)
- ✅ RSS feed & sitemap
- ✅ Reading progress bar
- ✅ Bookmarks & likes (localStorage)
- ✅ Disqus comments
