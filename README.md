# TechPulse

> Practical guides on ESP32 / Arduino projects and home repair, plus programming tips.

Live site: https://www.pulsehig.com

## Topics

- Embedded systems: ESP32, Arduino, sensors, relays, MOSFETs, I2C, deep sleep
- Home repair and smart-home energy savings
- Programming and troubleshooting

## Languages

English by default, with automatic translations (Chinese, Spanish, Hindi, French, Portuguese)
generated by `scripts/translate-articles.mjs`.

## Architecture

- Frontend: plain HTML / CSS / JavaScript (no framework)
- Backend: Supabase (articles, article_views, site_stats, forum, auth, storage)
- Hosting: GitHub Pages with the custom domain in `CNAME`
- SEO: `scripts/generate-seo.mjs` writes `a/`, `series/`, `rss/` and the sitemaps
- Articles: `scripts/daily-bot.mjs` writes one 1500-2500 word article per run with Groq
- PWA: `manifest.json`, `sw.js`, `offline.html`

## GitHub workflows

| File | Purpose |
|------|---------|
| `seo.yml` | Rebuilds static pages, sitemaps and feeds when `a/`, `data/`, `js/` ... change |
| `seo-feeds.yml` | Manual run: generates a new article, then rebuilds the SEO files |
| `translate-articles.yml` | Daily translation of new articles (03:00 UTC) |

Required repository secrets: `SUPABASE_URL`, `SUPABASE_SERVICE_KEY`, `GROQ_API_KEY`
(optional: `GROQ_MODEL`).

## Security

Only the admin account can write to the content tables. Policies live in
`supabase_security_fix.sql` (function `public.is_admin()`); the public key in the front-end
code can only read. Never put the service key in the repository.

## Local development

