USB Port Not Working? Diagnose It Before You RMA the Board

👤 TechPulse Team 📅 2026-10-03 ⏱ 6 min read
🎯 Difficulty: Intermediate ⏱ Fix time: 20 min 💰 Cost: Free–€15

One USB port stopped working and you assume the motherboard is damaged. In reality it is usually a corrupted USB hub state, a power delivery issue, or a bent pin you can see with a flashlight.

1. Look inside the port

Use a phone flashlight. Check for bent pins, lint, or a broken plastic tongue. Lint is the most common cause on laptops kept in bags.

2. Test with a known-good device

A USB flash drive and a mouse use different data lines. If the mouse works but the drive does not, the port's data pins are damaged.

3. Reset the USB hub (Windows)

Device Manager → Universal Serial Bus controllers → right-click each "USB Root Hub" → Uninstall
Reboot

Windows reinstalls the hubs on boot, which clears many "dead port" states.

4. Disable USB selective suspend

Power Options → Change plan settings → Advanced → USB settings → USB selective suspend → Disabled

This stops Windows from cutting power to ports it thinks are unused.

5. Check power delivery

A port that works with a mouse but not an external SSD is under-powering. Front-panel ports on desktops are notorious. Move the device to a rear port connected directly to the board.

6. Linux: reset the USB controller

lsusb
sudo usb_modeswitch -v 1234 -p 5678 -R
# or unbind/rebind:
echo -n "0000:00:14.0" | sudo tee /sys/bus/pci/drivers/xhci_hcd/unbind
echo -n "0000:00:14.0" | sudo tee /sys/bus/pci/drivers/xhci_hcd/bind

7. When it is truly dead

If the port never enumerates in BIOS either, the controller or the physical connector is damaged. A powered USB hub is the cheapest workaround; a laptop USB-C dock is the cleanest.

Summary

Inspect the port, reset the hubs, disable selective suspend, test power delivery, and check BIOS. Only if the port is dead in BIOS is it a hardware failure.
