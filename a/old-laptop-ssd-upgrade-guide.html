Turn a 2015 Laptop into a Fast Machine: SSD + RAM Upgrade Guide

👤 TechPulse Team 📅 2026-10-03 ⏱ 9 min read
🎯 Difficulty: Beginner ⏱ Fix time: 60 min 💰 Cost: €50–80

A laptop with an i5-5200U and 4 GB RAM is not slow because the CPU is old — it is slow because it is waiting for a 5400 rpm hard drive and swapping to disk. Replacing those two parts costs less than a new laptop and gives 10× the responsiveness.

1. Check what is inside

# Windows
wmic diskdrive get model,size,interfacetype
wmic memorychip get capacity,speed,devicelocator

# Linux
sudo lshw -class disk -class memory | less

Note whether you have a 2.5" SATA bay, an M.2 slot, or both. Most 2015 laptops have a 2.5" bay and sometimes an M.2 SATA (not NVMe) slot.

2. Buy the right parts

  • SSD: 500 GB SATA III (Crucial MX500 or Samsung 870 EVO). €45–55.
  • RAM: check the type. 2015 laptops use DDR3L-1600 SO-DIMM. 8 GB is €20–25.
  • External USB enclosure: €8. Needed for cloning.

3. Clone the old drive

Put the new SSD in the USB enclosure, then use Macrium Reflect Free or Clonezilla:

sudo clonezilla
# device-device mode → source: /dev/sda → target: /dev/sdb

Cloning preserves Windows activation and all your files. Takes 30–90 minutes.

4. Swap the drives

Open the laptop, remove the old HDD, install the SSD in its place. Put the old HDD in the USB enclosure — you now have an external backup drive.

5. Add RAM

Open the RAM slot, insert the SO-DIMM at 30°, press down until it clicks. If you have 4 GB + 4 GB, that is 8 GB total. If the laptop supports dual channel, matching pairs are faster.

6. First boot checks

# Confirm SSD is detected and TRIM is on
fsutil behavior query DisableDeleteNotify   # should be 0
# Check RAM
wmic memorychip get capacity,speed

7. Optional: clean install

If the old Windows install is 5 years old, a clean install on the SSD is even faster. Back up your data first, then use the Windows Media Creation Tool.

8. What to expect

  • Boot time: 45 s → 8 s
  • App launch: 6 s → 1 s
  • Windows updates: 40 min → 5 min
  • General feel: unusable → snappy

Summary

Clone the HDD to a SATA SSD, drop in 8 GB of RAM, and a 2015 laptop becomes perfectly usable for browsing, Office and light development. Total cost: under €80.
