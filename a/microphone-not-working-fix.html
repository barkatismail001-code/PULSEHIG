Microphone Not Working? Fix Mute, Levels and Privacy Settings

👤 TechPulse Team 📅 2026-10-03 ⏱ 5 min read
🎯 Difficulty: Beginner ⏱ Fix time: 10 min 💰 Cost: Free

You sound like a robot or nothing at all. In 2026, the most common cause is not the mic — it is Windows privacy settings and "exclusive mode" locking the device to one app.

1. Look for a hardware mute

Many headsets and USB mics have a physical mute button or a mute LED on the inline control. Check it first.

2. Windows microphone privacy

Settings → Privacy & security → Microphone → Microphone access → On
Let apps access your microphone → On

3. Set the correct input device

Settings → System → Sound → Input → choose your microphone

Then speak and watch the input level bar. If it does not move, the mic is muted or dead.

4. Disable exclusive mode

Sound Control Panel → Recording → [mic] → Properties → Advanced → uncheck "Allow applications to take exclusive control"

This fixes the classic "works in Discord but not in Zoom" problem.

5. Boost the level

Recording → [mic] → Properties → Levels → Microphone: 80, Microphone Boost: +20 dB

6. Change the default format

Advanced → Default Format → 2 channel, 16 bit, 44100 Hz (CD quality)

Some USB mics fail at 48000 Hz or 24-bit. 44100 Hz 16-bit is the most compatible.

7. Reinstall the audio driver

Device Manager → Audio inputs and outputs → Uninstall → Reboot

8. Test in a browser

Open webcammictest.com. If it works there but not in your app, the app has its own input selection — fix it in the app's settings.

Summary

Check the hardware mute, grant privacy access, disable exclusive mode, set 16-bit/44.1 kHz, and reinstall the driver. That fixes the vast majority of mic issues.
