Printer Offline on Windows? Fix It in 10 Minutes

👤 TechPulse Team 📅 2026-10-03 ⏱ 5 min read
🎯 Difficulty: Beginner ⏱ Fix time: 10 min 💰 Cost: Free

The printer is on, connected to Wi-Fi, and still Windows shows "Offline". In 90% of cases the printer changed IP address, or Windows is using a stale SNMP status check. Both are fixable in minutes.

1. Restart the print spooler

net stop spooler
del /Q %SystemRoot%\System32\spool\PRINTERS\*
net start spooler

Run as Administrator. This clears stuck jobs that make Windows mark the printer offline.

2. Disable SNMP status

Control Panel → Devices and Printers → [printer] → Printer properties → Ports → Configure Port → uncheck "SNMP Status Enabled"

This is the single most effective fix for network printers that randomly show offline.

3. Give the printer a static IP

Log into the printer's web interface and set a static IP outside your DHCP pool. Then re-add the printer using that IP.

4. Remove and re-add the printer

Settings → Bluetooth & devices → Printers & scanners → Remove device
Then: Add device → The printer that I want isn't listed → Add using TCP/IP → 192.168.1.50

5. Check the print queue on the printer itself

Some printers get stuck with a corrupted job and refuse all new connections. Power-cycle the printer for 30 seconds.

6. Use the manufacturer driver, not the generic one

Microsoft's IPP class driver is convenient but often causes "offline" status. Install the full driver from HP, Canon or Brother.

Summary

Restart the spooler, disable SNMP status, assign a static IP, and re-add via TCP/IP. That fixes the vast majority of "offline" printers on Windows.
