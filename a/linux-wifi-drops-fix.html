Wi-Fi Keeps Dropping on Linux? Fix It in 15 Minutes

👤 TechPulse Team 📅 2026-10-03 ⏱ 6 min read
🎯 Difficulty: Beginner ⏱ Fix time: 15 min 💰 Cost: Free

Your laptop drops Wi-Fi every few minutes, the router is fine, Windows works — and you blame the driver. In reality, 80% of Linux Wi-Fi drops come from three settings: aggressive power saving, a wrong regulatory domain, and channel overlap.

Step 1 — Read the kernel log, not the GUI

sudo dmesg -w | grep -i -E "wlan|iwlwifi|ath|rtw|disconnect"

Watch this while the disconnect happens. Typical messages and their meaning:

  • "deauthenticating ... reason 4" — the AP kicked you. Interference or a full client table.
  • "firmware crash" — driver/firmware bug. Update the kernel or firmware package.
  • "beacon loss" — signal too weak. Reposition or change channel.

Step 2 — Disable Wi-Fi power saving

iw dev wlan0 get power_save
sudo iw dev wlan0 set power_save off

Make it permanent with NetworkManager:

sudo tee /etc/NetworkManager/conf.d/wifi-powersave-off.conf <<'EOF'
[connection]
wifi.powersave = 2
EOF
sudo systemctl restart NetworkManager

Step 3 — Set the correct regulatory domain

iw reg get
sudo iw reg set DE
echo 'REGDOMAIN=DE' | sudo tee /etc/default/crda

Step 4 — Stop the card from roaming to a worse AP

sudo tee /etc/NetworkManager/conf.d/wifi-roaming.conf <<'EOF'
[connection]
wifi.scan-rand-mac-address=no

[device]
wifi.backend=wpa_supplicant
EOF

Step 5 — Pick a clean channel

sudo iw dev wlan0 scan | grep -E "SSID|freq|signal" | head -40

On 2.4 GHz only channels 1, 6 and 11 do not overlap. On 5 GHz prefer UNII-3 (149–165).

Step 6 — If it is still unstable

  • Disable 802.11n/ac aggregation on the router for that client.
  • Turn off WPA3 transition mode — it breaks many older Linux drivers.
  • Try the iwlwifi option 11n_disable=8 for Intel cards.
  • Replace the module with a MediaTek MT7921 or an Atheros AR9271.

Summary

Read dmesg first. Turn off power saving. Set the country code. Pick a non-overlapping channel. Those four steps fix the vast majority of Linux Wi-Fi disconnects.
