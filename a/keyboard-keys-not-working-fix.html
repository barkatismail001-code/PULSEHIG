Keyboard Keys Not Working? Fix Hardware and Software Causes

👤 TechPulse Team 📅 2026-10-03 ⏱ 6 min read
🎯 Difficulty: Beginner ⏱ Fix time: 15 min 💰 Cost: Free–€10

One key or a whole column stopped responding? Before replacing the keyboard, test it with a web-based key tester, disable Filter Keys, and check whether the issue follows the keyboard or the computer.

1. Test with a keyboard tester

Open keyboardtester.com in a browser. Press every key. This tells you exactly which keys are dead and whether it is a matrix (whole row/column) or a single key.

2. Disable Filter Keys

Settings → Accessibility → Keyboard → Filter Keys → Off

Filter Keys ignores brief or repeated keystrokes. It is the #1 reason a keyboard "stops typing" after an update.

3. Try a different USB port and PC

If the keyboard works on another computer, the problem is the driver or OS. If it fails everywhere, it is hardware.

4. Reinstall the HID driver

Device Manager → Keyboards → right-click → Uninstall device → Reboot

5. Clean the membrane or switches

Membrane keyboards: remove the back screws, separate the layers, and clean the contact pads with isopropyl alcohol.
Mechanical keyboards: use a keycap puller to remove the cap, then a switch puller or compressed air. Replace the switch if it is hot-swappable.

6. Check for liquid damage

If a whole column of keys is dead, liquid likely damaged the matrix traces. Unplug, disassemble, clean with isopropyl alcohol, and dry for 24 hours.

7. Test with Linux

sudo evtest
# or
sudo showkey

If Linux also sees no scancode, the key is physically dead.

Summary

Test with a keyboard tester, disable Filter Keys, try another PC, reinstall the driver, and clean the contacts. If a matrix row is dead, it is hardware — replace or repair.
