Windows 11 Slow After an Update? 8 Fixes That Actually Work

👤 TechPulse Team 📅 2026-10-03 ⏱ 7 min read
🎯 Difficulty: Beginner ⏱ Fix time: 20 min 💰 Cost: Free

A major Windows 11 update can turn a fast PC into a laggy mess — boot times double, the Start menu stutters, and file explorer takes seconds to open a folder. In most cases the hardware is fine; the update left behind stale caches, half-migrated drivers and a broken search index.

1. Confirm what is actually slow

Open Task Manager (Ctrl + Shift + Esc) and watch the Performance tab during a slowdown. Note whether it is CPU, RAM, disk or GPU at 100%. That single step tells you which fix to use.

2. Let the update finish in the background

Windows 11 continues installing "post-update tasks" for up to 48 hours. Check:

Get-Service -Name wuauserv, UsoSvc, DoSvc | Select Name, Status

If they are running, plug in the laptop, leave it idle for an hour and reboot once. Many "slow after update" reports disappear on their own.

3. Disable startup bloat

Task Manager → Startup apps → disable everything you do not recognise

Common offenders after an update: Teams, OneDrive, Adobe Updater, Xbox Game Bar, Edge background mode.

4. Rebuild the Windows Search index

A corrupted index is the #1 cause of "Start menu lag" after updates.

Control Panel → Indexing Options → Advanced → Rebuild

Let it finish (30–90 minutes). Do not use the PC heavily during this.

5. Clear the Windows Update cache

net stop wuauserv
net stop bits
rd /s /q C:\Windows\SoftwareDistribution\Download
net start wuauserv
net start bits

Run as Administrator. This removes leftover update payloads that can be tens of gigabytes.

6. Reinstall the GPU driver cleanly

Updates often ship a broken generic driver. Download the latest from NVIDIA / AMD / Intel, then use DDU (Display Driver Uninstaller) in Safe Mode before installing.

7. Disable Memory Integrity (VBS) if you do not need it

Windows Security → Device security → Core isolation → Memory integrity → Off

This can cost 5–15% CPU performance on older chips. Only disable if you accept the security trade-off.

8. Check for a rollback window

You have 10 days to go back:

Settings → System → Recovery → Go back

Summary

Give the update 48 hours, kill startup bloat, rebuild the search index, clear the update cache, and reinstall the GPU driver. That sequence fixes the vast majority of post-update slowdowns without a clean install.
