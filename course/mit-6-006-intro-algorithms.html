Overview

Three classic comparison sorts.

Key ideas

  • Insertion: O(n^2).
  • Merge: O(n log n), stable.
  • Heap: O(n log n) in place.

Worked example

1M integers: insertion takes hours, merge takes seconds.

Common pitfalls

  • Using insertion on large arrays.

Why it matters

Any comparison sort is Omega(n log n).

Overview

BST stores keys so in-order traversal is sorted.

Key ideas

  • Insert/search/delete: O(h).
  • Degenerate trees: h = n.
  • AVL maintains h = O(log n).

Worked example

Inserting sorted keys gives a linked list. AVL rebalances.

Common pitfalls

  • Forgetting to update heights.

Why it matters

A balanced tree turns a list into a fast dictionary.

Overview

Graphs model networks, dependencies, state spaces.

Key ideas

  • BFS: levels, shortest unweighted paths.
  • DFS: deep first, cycles.
  • Both O(V+E).

Worked example

Friendship graph: BFS finds degrees of separation.

Common pitfalls

  • Using DFS for shortest paths.

Why it matters

Traversal underlies routing and scheduling.
